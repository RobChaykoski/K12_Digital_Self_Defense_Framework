# K-5 Cyber Adventures: Teacher Guide

## Introduction

Welcome to the K-5 Cyber Range! This guide will help you implement engaging cybersecurity education for your students using OpenCyberRange.

## Getting Started

1. **Access Setup**: Students log in through the web interface
2. **Track Creation**: Use the K-5 track for age-appropriate challenges
3. **Lab Assignment**: Assign scenarios from the curriculum
4. **Progress Monitoring**: Track student achievements and completion

## K-5 Scenario Types

### Network Discovery Adventures
Students learn basic network concepts through safe exploration

### Treasure Hunt Challenges  
Simple file retrieval tasks with clear objectives

### Digital Detective Work
Pattern recognition and evidence analysis skills

## Engagement Strategies

### Visual Learning
- Use screenshots in instructions
- Include visual cues for younger learners
- Create colorful, student-friendly interfaces

### Progressive Difficulty
Start with simple commands like `ping`
Progress to more complex network discovery

### Immediate Feedback
- Auto-grading validates student actions
- Hint system supports struggling learners
- Achievement badges motivate completion

## Implementation Tips

### For New Teachers
1. Start with pre-made scenarios from the platform
2. Customize difficulty levels for your class
3. Monitor progress through the admin dashboard

### Student Support
- Provide printed instructions for younger students
- Use the hint system to scaffold learning
- Celebrate achievements with certificates or badges

## Assessment and Progress Tracking

The platform provides:
- Completion statistics
- Time spent on exercises  
- Flag submission records
- Achievement tracking

## Troubleshooting

### Common Issues
1. **Connection Problems**: Ensure students have proper VPN setup
2. **Access Denied**: Verify student accounts are enabled
3. **Lab Not Starting**: Check resource allocation and server status

For questions or support, contact your platform administrator.
