# 🖼️ Assets Directory

This folder stores images, logos, QR code outputs, and downloadable resources.

## 📁 Structure
```
assets/
├── logos/          # School / program branding
├── qr_codes/       # Generated QR codes for CTF worksheets
├── templates/      # Editable handout templates (DOCX/PPTX)
└── screenshots/    # LMS preview images
```

## 📝 Notes
- Keep files under 2MB where possible
- Use PNG for transparent backgrounds, JPG for photos
- QR codes should link to HTTPS endpoints
